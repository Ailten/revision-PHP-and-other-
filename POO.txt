
// ------> POO (programmation orienté objet).

POO is a paradigme of programmation.
by creating bricks logiciels (object).
an object represent an entity or a concept (encapsulation).
objects can interact with eatch other to create complex fonctionnement.
object contains internal structure (and comportment), (attributs and function).

a "class" is like a "blue-print", and an "instance" is the object unique create with the blue-print.
an object can erite from another (eritage), when A erite from B, A contains all attributs and function of B.
than we say A is child and B is parent.

private : is a key word when attribute can be call/use only from the class it self (who own the attribute).
protected : when is call from the class owner or a child.
public : when is call from every where.

an Interface is like a promes of what the class should implement (as function and attributes).

an abstract class is a class that can't be instanciate (use only as parent).

Static is a key word to define an attribute as "unique memory pointer" for every instance (share the same value).

// ------> 4 principes of POO :

Abstraction : represent complex concept on a simplify way (describe the essentiel caractéristique of an object).

Encapsulation : mask the complexity inside of an object (private).

Eritage : create new class based on other existant (to share attributs and methodes), to prevent code repetition.

Polymorphisme : allow an object to act diferently depend on context, (methode with same name, variable taking child, ...).



// ------> Pratique.


class Cat  // a class.
class Cat extend Animal  // heritage.
abstract class Animal  // abstract class (can't be instanciate).
interface ISignable  // interface (like contract).

public Cat(){}  // constructor (function call when an instance is create).
public Cat() : base(){}  // same, call the constructor parent (with base).

public virtual void myFunc(){}  // mark a function as "virtual" (can be override by a child).
public override void myFunc(){}  // override a function of parent (in a child), need to be virtual.
this.myFunc();  // call a function of my current instance from my class (this).
base.myFunc();  // call a function of my parent (the vertion of my parent, not overrided).

private  // acces from the class only.
public  // acces from every where.
protected  // acces from the class and his child.

void myFunc(){}
void myFunc(int num){}  // allow many function with same name but distinct parameters.
static void myFunc(){}  // static make a function (or class, or attribute), refer to the same memory address for every instance : 
                        // like it's link to the class not the instance (share for every instance).

Animal a = Cat()  // polymorphisme, allow to stock a child class in a variable of type parent.
a.GetType() == typeof(Cat)  // check if an instance is a precise type.
a is Cat  // check if an instance implement this type (return true if "a" is a Cat or a child of Cat).
a as Cat  // cast an instance in a type (work if a is a Cat or a child of Cat), allow to get a more precise type to acces more functions/attribute.
if (a is Cat c){}  // cast "a" in a cat (c) only if it can (variable "c" exist only on scope if).

private string _name = "test"
public string name{  // allow to remap getter and setter of an attribute (and declare script execute when call).
    get{ return this._name; }
    set{ this_name = value; }  // (it can implement both of a single one).
}
public string surname { get; set; }  // short vertion, to declare an attribute can be get and set.

public static Cat operator +(Cat catA, Cat catB) => catA.name + catB.name  // allow to surcharge basic operator (to define how class should be act when this operator is used), can be a block function.
public static explicit operator int(Cat catA) => catA.name.Length;  // re-define the cast action (explicite: when write by dev).
public static implicit operator int(Cat catA) => catA.name.Length;  // re-define the cast action (implicit: auto cast by code).
public static void MyFunc(this Cat cat){}  // "this" as parameter, allow to déclare a function from another class (extention methode), only on static method.

class Cat<T>  // generic type allow to send a Type in a context (class/function) and adapt how code gonna treat it.
class Cat<T> where T : IEatable  // same, add a restriction on the generic type (only those who implement IEatbale (work on class to)).
